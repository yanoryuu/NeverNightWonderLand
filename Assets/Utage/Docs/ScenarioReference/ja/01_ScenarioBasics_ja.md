# シナリオ記述の基本

宴（Utage）のシナリオファイルの基本構造。

## ファイル形式

- Excelファイル（.xls / .xlsx）または CSVファイル（宴4以降）。
- Excelは1ファイルに複数シート。CSVは1ファイル＝1シート（**ファイル名（拡張子除く）がシート名になる**）。
- シートは「設定シート」（Character, Texture, Sound, Layer, Param 等 → [07_SettingSheets_ja.md](07_SettingSheets_ja.md)）と「シナリオシート」（それ以外の任意名）に分かれる。

### CSVファイルの物理仕様

- 文字コード: **UTF-8**（BOMの有無はどちらでも可。宴のツールが出力するCSVはBOM付きなので、合わせておくのが無難）
- 改行コード: CRLF / LF どちらでも可
- クォート: RFC 4180準拠。**カンマ・改行・`"` を含むセルは `"` で囲む**。セル内の `"` は `""` と二重に書く。クォート内なら改行も1セルに含められる
- 行末の空フィールドは省略可（`Bg,背景1` のように、値のある列まで書けばよい）

## シナリオシートの列

先頭行が列名。列は名前で識別されるため並び替え可能（Animation/EyeBlink/LipSynchシートを除く）。不要な列は削除してよい。

```
Command, Arg1, Arg2, Arg3, Arg4, Arg5, Arg6, WaitType, Text, PageCtrl, Voice, WindowType, <言語名>...
```

| 列 | 意味 |
|---|---|
| Command | コマンド名。空欄の場合は下記「コマンド省略時の解釈」 |
| Arg1〜Arg6 | コマンドの引数。意味はコマンドごとに異なる。**フェード秒数・待機秒数などの時間系は原則 Arg6** |
| WaitType | 演出系コマンドの待機方法（下記） |
| Text | 表示テキスト（地の文・セリフ） |
| PageCtrl | ページ送り制御（下記） |
| Voice | ボイスファイル名（Soundシート登録名） |
| WindowType | 使用メッセージウィンドウ名 |
| 言語名（例: English） | 多言語対応時の翻訳テキスト列 |

## コマンド省略時の解釈

| 記述状態 | 解釈 |
|---|---|
| Command空欄 + Arg1にキャラ名 | セリフ・キャラクター表示（Characterコマンド相当） |
| Command空欄 + Textのみ | 地の文のテキスト表示（Textコマンド相当） |
| Command列が `*ラベル名` | シナリオラベル定義 |
| Command列が `//〜` または `Comment` | コメント行（無視される） |

## シナリオラベル

- `*ラベル名` … 全体で一意なラベル。Jump・Selection等の分岐先に `*ラベル名` で指定。
- `**ラベル名` … ローカルラベル（シート内限定）。シートごとに同名可。定義行は内部的に `シート名*ラベル名` という完全名に変換される。
  - **同一シート内から参照する場合**は、定義時と同じ `**ラベル名` をそのまま書けばよい（Jump等の参照側でも同じ変換ロジックが働き、書いたコマンドが属するシート名で自動的に補完されるため）。
  - **他シートから参照する場合**は `*シート名*ローカルラベル名`（先頭は`*`ひとつ）と明示的にシート名を書く必要がある。
- **シート名はそのままシナリオラベルとしても扱われる**（各シートの先頭が `*シート名` 相当になる。シート先頭に明示的なラベル行を書く必要はなく、`Jump,*シート名` でそのシートの先頭へ飛べる）。
- シナリオの開始ラベルは既定で `Start`（AdvEngineStarterの設定で変更可）。
  **複数のシナリオファイル（シート）を使う場合、実際の開始点となるラベル（既定`Start`）はプロジェクト全体で1シートのみに定義すること**
  （同名ラベルの二重定義はエラーになる。08章参照）。他のシートは自身のシート名が自動的にラベルになるため、
  わざわざ`*Start`を重ねて定義する必要はなく、そのシートへは `Jump,*シート名` で入れる。

## コメントアウト

| 対象 | 記法 |
|---|---|
| シート全体 | シート名（Excel）またはファイル名（CSV）の先頭に `#` |
| 列全体 | 列名の先頭に `//` |
| 行全体 | 行の先頭セルに `//`、または Command列に `Comment` |

CSVは1ファイル＝1シートのため、ファイル名の先頭に `#` を付けるとファイルごとインポート対象から除外される（Excelのシート名コメントアウトと対称の仕様）。インポート対象はフォルダ単位で指定されることが多いため、作業用・テスト用のCSVを一時的に除外したい場合に使う。

## PageCtrl（ページ送り制御）

| 値 | 動作 |
|---|---|
| （空欄） | 改ページ入力待ち（デフォルト） |
| Input | 入力待ちの後、次コマンド実行（改行・改ページなし） |
| InputBr | 入力待ちの後、改行 |
| InputBrPage | 入力待ちの後、改ページ |
| Next | 入力を待たずに次コマンド実行 |
| Br | 入力を待たず改行して次へ |
| BrPage | 入力を待たず改ページして次へ |

テキスト内の改行は `\n`。Excelなら Alt+Enterでも可。

**Command・Arg1・Text列をすべて空欄にしてPageCtrl列だけ書いた行**は、エラーにならず**Textコマンド（テキスト空）として解釈され**、ページ送りだけが実行される
（`AdvParser.IsEmptyTextCommand()` がPageCtrl列の内容を先にチェックしているため）。
「テキストの無い行でページ送りだけ発生させたい」という用途はこの書き方で実現できる。

## WaitType（演出の待機方法）

Tween・Shake・FadeIn/Out・PlayAnimation・ImageEffect等の演出系コマンドで指定可能。

| 値 | 動作 |
|---|---|
| （空欄） | 演出完了まで次のコマンドを待つ |
| PageWait | ページ送り時に演出終了を待つ |
| InputWait | クリック入力後に演出終了を待つ |
| Add | 次の演出の終了タイミングと同期して待つ |
| NoWait | 待たずに即座に次へ（この間のセーブは非推奨） |
| Skippable | 演出終了待ちだがクリックでスキップ可能 |
| PageWaitSkippable / InputWaitSkippable / AddSkippable | 上記のスキップ可能版 |
| SkippableOnWaitThread | 演出スレッド専用。メインで WaitThread 使用時のみスキップ可 |
| SkipOnInput | クリック入力で演出を強制終了 |
| SkipOnBrPage | ページ送りで演出を強制終了 |

※キャラクター表示のフェードには WaitType を直接指定できない。WaitFadeObjects コマンドで待機する。
※メッセージウィンドウ対象の演出は、`PageWait` でテキスト表示と並行実行させるのが定石（詳細: [03_Commands_Effects_ja.md](03_Commands_Effects_ja.md) の「実践パターン」）。

## テキストタグ（TextMeshPro版）

TextMeshPro標準のリッチテキストタグ（`<b>` `<i>` `<color>` `<size>` `<sprite>` 等）が page タグ以外そのまま使える。宴の独自タグ:

| タグ | 書式 | 意味 |
|---|---|---|
| ruby | `<ruby=るび>対象</ruby>` | ルビ |
| em | `<em=文字>対象</em>` | 傍点（`<em=●>` など文字指定可） |
| param | `<param=変数名>` | シナリオ変数の値を表示 |
| format | `<format={書式}:変数名>` | C#書式指定つき変数表示（例 `<format={0,3}:num>`） |
| speed | `<speed=秒>対象</speed>` | 1文字あたりの表示秒数を指定（`<speed=0>`で瞬間表示） |
| interval | `<interval=秒>` | その位置で文字送りを指定秒停止 |
| tips | `<tips=ID>対象</tips>` | TIPS機能へのリンク |
| url | `<url=URL>対象</url>` | ハイパーリンク（クリックでブラウザ） |
| dash | `<dash=文字数>` | 長い横棒。**非推奨**（使用しないこと） |
| skip_text | `<skip_text>` | それ以降のテキスト表示をスキップする（言語を問わず使える一般タグ） |
| skip_page | `<skip_page>` | **ローカライズ専用**。翻訳先の言語列のセルに、テキストの代わりにこの1語だけを書くと、その言語選択時はページ自体が丸ごとスキップされる（そのページを訳す必要がない場合に使用。ページ内の全テキストコマンドが`<skip_page>`である必要がある）。詳細は[09_Localization_ja.md](09_Localization_ja.md)を参照 |

## マクロ

複数行にわたるコマンドの組み合わせ（定型演出等）に名前を付けて、シナリオ中から1行で呼び出せるようにする仕組み。
同じ処理を何度も書く手間と、修正時に該当箇所を全部書き換える手間を減らせる。
呼び出し側は展開後のコマンド列に置き換わるだけなので、通常のコマンドと同様にシナリオ中のどこにでも書ける。

シート名が `Macro` または `Macro`+数字（`Macro1`, `Macro2`...）のシートに定義する（`AdvMacroManager.IsMacroName()`。それ以外のシート名は対象外）。
定義: Command列 `*マクロ名` で開始、`EndMacro` で終了。呼び出し: Command列にマクロ名を書くだけ（全シナリオシートから可）。

- **引数**: マクロ内で `%Arg1` `%Text` など `%列名` で参照。呼び出し行の該当列の値が代入される。
- **デフォルト引数**: `*マクロ名` の行の各列に書いた値が、呼び出し時空欄の場合に使われる。
- **エンティティ**: マクロ内で `&パラメーター名` と書くと実行時のパラメーター値を動的参照（マクロ内限定。インポート時エラーチェック不可。PageCtrl等コマンド実行前に必要な列では機能しない）。
- **構造化マクロ（宴4.2.6以降）**: `Args` 列に `prop1=値1,prop2=値2` 形式でまとめて渡し、マクロ内で `%列名.プロパティ名` で参照。StructuredMacroParser の ScriptableObject を CustomProjectSetting に設定して使う。

サンプル（Sample/Scenarios の Macro.csv を、標準の列順（`Command,Arg1,Arg2,...`。Args列なし）に合わせて書き直したもの）:

```csv
//フェードつきのBG切り替え
*FadeBg
FadeOut,%Arg2,,,,,%Arg3
Bg,%Arg1
Wait,,,,,,%Arg4
FadeIn,%Arg2,,,,,%Arg5
EndMacro

//デフォルト引数つき
*FadeBgDefault,,white,.2,1,.2
FadeBg,%Arg1,%Arg2,%Arg3,%Arg4,%Arg5,%Arg6
EndMacro
```

※実物のSample/Scenarios/Macro.csvは、構造化マクロ用の`Args`列（Command列の直後）を含むヘッダーで
書かれているため、そのまま転記すると列がひとつずれる。本サンプルはArgs列を使わない前提で
列位置を調整済み。

### サブルーチンとマクロの使い分け

| 要件 | サブルーチン | マクロ |
|---|---|---|
| 独立したシナリオの呼び出し・復帰 | ○ | × |
| 同一ページ内の定型処理 | × | ○ |
| 既読判定 | 呼び出し先で一括 | 使用箇所ごとに個別 |
| 引数による内容の変化 | ×（パラメーター併用） | ○（エンティティ） |

サブルーチンの詳細は [05_Commands_FlowControl_ja.md](05_Commands_FlowControl_ja.md) の「サブルーチン」節を参照。
