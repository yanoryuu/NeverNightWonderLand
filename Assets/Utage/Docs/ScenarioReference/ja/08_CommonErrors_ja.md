# よくあるエラーと対処

宴のシナリオをインポート・実行したときにUnityコンソールへ出るエラーの読み方と、典型的な間違いごとの対処。
出典: コード実装（各コマンドのエラー出力箇所の直接確認）＋実機での動作確認。

## エラーの読み方

インポート時のエラーの多くは次の形式でコンソールに出る（実測例）。

```
存在しない背景 is not contained in file setting
MyScenario:3 <color=#ff0000ff> Bg, 存在しない背景,</color>
<b>Assets/.../MyScenario.csv</b>  : 3
```

- 1行目がエラーメッセージ、2行目が `<シート名>:<行番号>` ＋該当行の内容（赤色マークアップ）、3行目がファイルパス＋行番号。**エラー行の中身がそのままログに含まれる**ため、ログだけで原因行を特定できる。
- **行番号はファイル先頭からの行数（ヘッダー行を含む・1始まり）**。CSVの場合、シート名＝ファイル名（拡張子除く）。
- コマンドはインポート時に構築・検証されるため、引数・ラベル・定義名の間違いは**実行前にほぼ検出される**。インポートがエラーなしで通れば、記述面の大半は正しい。
- エラーは1回のインポートで**まとめて出る**（引数・定義名系 → ラベル二重定義 → If構文 → Param式 → ラベルリンク切れ、の順）。行の並び順とログの順序は一致しないため、修正時はログの `シート名:行番号` を基準にすること。
- エラーメッセージは環境の言語設定により日本語または英語で出る（本書は日本語形式で記載。固定英文のものはそのまま記載）。

### 修正の手順

1. `シート名:行番号` でエラー行を特定する
2. メッセージ中の名前（ラベル・キャラ名等）を、プロジェクトの設定シート（[07_SettingSheets_ja.md](07_SettingSheets_ja.md) の各シート）の定義と突き合わせる
3. 修正して再インポートし、エラーが消えたことを確認する

## インポート時エラー一覧

| 間違い | エラーメッセージ | 対処 |
|---|---|---|
| Bg/BgEvent/Sprite/Particle等に未定義の画像ラベル | `<ラベル> is not contained in file setting`（続けて `Not contains <ラベル> in Texture sheet` も出る） | Textureシートに定義されているラベルを使う |
| Bgm/Se/Ambience/Voice等に未定義のサウンドラベル | `<ラベル> is not contained in file setting` | Soundシートに定義されているラベルを使う |
| Arg3等に未定義のレイヤー名 | `<名前> is not contained in layer setting` | Layerシートに定義されているレイヤー名を使う |
| 定義済みキャラの未定義パターン（表情等） | `<キャラ名>, <パターン> is not contained in Character Sheet` | Characterシートにあるパターン名を使う |
| Jump/Selection等の飛び先ラベルが存在しない | `<ラベル>: はリンク先が存在しないシナリオラベルです` | ラベル定義行（`*ラベル名`）を追加するか、飛び先名を修正 |
| 同名シナリオラベルの二重定義 | `<ラベル>: 二重に定義されたシナリオラベルです`（**行番号は出ない**・ファイル名のみ） | 片方をリネーム（シート内限定なら `**ローカルラベル` も検討）。**このエラーは最優先で直すこと**: 重複ラベル配下の区間はインポート対象から外れるため、その区間内のParam式エラー等が検出されないまま残る |
| ラベル指定の `*` 忘れ | `<値>:はシナリオラベルではありません` | 飛び先指定は `*ラベル名` の形式で書く |
| コマンド名のtypo（例: `Bgg`） | `不正な記述です` | **「コマンド名が違う」とは言ってくれない**点に注意。その行のCommand列の綴りをコマンド一覧（02〜06章）と照合する |
| Param式の誤り（未定義変数・`;`連結など） | `<トークン> :不明なパラメーターです。` ほか（`式の結果がbool型ではありません` / `不正な式の記述です`） | 変数はParamシートに定義されたもののみ。**複数の代入を`;`で1セルに連結できない**（Param行を分ける） |
| If系の構文誤り（IfなしでElseIf/Else/EndIf等） | `Syntax error in if-else commands.Set the if command first.`（この項目のみ言語設定によらず英語） | If〜ElseIf〜Else〜EndIf の対応を揃える |
| 数値列に変換できない値（列ズレの典型症状） | `<n> 列目のデータ: <値> を値に変換できません。正しい書式で入力してください` ＋続けて `列:<列名> は存在しないかデータが空です。` の2件セット | **列ズレを疑う**。カンマの数・引数の位置（特に時間系=Arg6）を確認 |
| WaitTypeの値の誤り | `UNKNOWN WaitType` | WaitType列に書ける値は01章の一覧のみ |
| CSVの `"`（引用符）の閉じ忘れ | `Invalid CSV format. <ファイルパス> Double quotes are not closed. (line:<開始行番号>)` | ファイルパスと、閉じていない`"`が開始した行番号が表示される。当該CSVはインポート対象から除外されるが、**他のCSVのインポートは中断されず続行される**。囲み方は01章参照 |

## インポートでは検出されない間違い（落とし穴）

- **未定義のキャラ名はエラーにならない**。Characterシートにない名前をArg1に書くと「名前表示のみ（立ち絵なし）」として正常に通ってしまう。キャラ名のtypoは「絵が出ない」という見た目の異常でしか気づけないため、生成後にキャラ名の綴りをCharacterシートと突き合わせること。
- 列ズレしても値の型がたまたま合う場合は素通りする（例: レイヤー名のつもりの文字列が別の文字列引数として解釈される）。インポートが通っても引数の位置が正しいかは保証されない。
- 実行時にしか検出されないエラーもある: SetPivot/Tween/GUI操作系の対象オブジェクト名の間違い（`<名前> is not found` 等）、SendMessageByName系のシーン内オブジェクト名など、「実行時のシーン状態」に依存するもの。
- 実行時エラー事例: プロジェクトにLayerシートが1枚も無い状態でBg等を使うと、古いバージョンではインポートは通るが実行時にNullReferenceExceptionになる（新しいバージョンではデフォルトレイヤーが自動追加され解消済み）。原因不明のNREが出たらLayerシートの有無を確認する。
