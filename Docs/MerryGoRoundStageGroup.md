# ステージ群「メリーゴーランド」設計書

テーマ: **メリーゴーランド (回転木馬)**。
準備室を出た先に広がる、遊園地の目玉アトラクション「大回転木馬」とその地下機関部を舞台にしたステージ群。
地上は華やかな木馬の広場、地下は木馬を回すための歯車・鎖・ピストンが並ぶ機関部という対比で、上下分岐の探索を作る。
現段階は見た目を付ける前のグレーボックス (床・壁・オブジェクト・敵・設備のみ。装飾なし)。

## 全体フロー

```
準備室 (地上レベルに新出口)
   ↓
[1] 回転木馬の大広間 (拠点: セーブ / ショップ / 鍛冶師)
   ↓
[2] 木馬の門 (中ボス① 長方形アリーナ・扉閉鎖)
   ↓
[3] 昇降分岐塔 (上下分岐)
   ├─ 上へ → [4]→[5]→[6]→[7] → [8] 上中ボス (地上ルート 4シーン+ボス)
   └─ 下へ → [9]→[10]→[11]→[12] → [13] 下中ボス (地下ルート 4シーン+ボス)
```

- 中ボス① (木馬の門) を倒すと進行フラグ `MidBoss1` が立ち、大広間の**鍛冶師から赤ハサミ強化 (2段ジャンプ+滑空)** を受けられる。
- 各ボスエリアは入場すると扉が閉まり、撃破まで移動不可。撃破後は扉が開き、ボスは再出現しない (進行フラグで管理。拠点で休んでも復活しない)。
- 各ルートは素の状態 (強化なし) で踏破できる高低差で設計する (跳び上がり高低差 3.0 以下 / すり抜け床活用)。2段ジャンプ取得後はショートカットが楽になる。

## シーン一覧

### [1] CarouselHallScene 「回転木馬の大広間」 (拠点)
- **コンセプト**: 大回転木馬の真下にある地下大広間。安全地帯 (敵なし)。少し大きめの拠点。
- **構造**: 横長の大部屋 (幅約 56、内部高さ 12、天井あり)。中央に回転軸の大柱 (左右から回り込める)。床は平坦、左右端に緩い段差。
- **設備**:
  - **セーブポイント** (既存 SavePoint → ホーム画面: 全回復/補充/攻撃入替/セーブ)
  - **ショップ** (新規 ShopKeeper): 糸を通貨にアイテムを購入 (まち針3 / ミシン針3 / 布カッター4 / 糸玉4 / ボビン爆弾5 / 針山5)
  - **鍛冶師** (既存 Blacksmith + 解禁条件): `MidBoss1` フラグ後に赤ハサミ (2段ジャンプ) を授ける。未達成時は「門の先の暴れ馬をどうにかしてくれ」
- **接続**: 左 ↔ 準備室 (地上レベルの新出口)。右 → [2] 木馬の門。

### [2] CarouselGateArenaScene 「木馬の門」 (中ボス①)
- **コンセプト**: 大広間と園内を隔てる門前の間。**シンプルな長方形**の空間で、逃げ場のない初ボス戦。
- **構造**: 幅 38 × 内部高さ 9 の長方形。床は完全な平坦。左右の出入口に**ボスゲート** (入場で閉鎖)。
- **ボス**: 「暴走木馬」— 地上突進型 (重装甲 Heavy 設定・大型)。撃破でゲート開放 + `MidBoss1`。
- **接続**: 左 ↔ [1] 大広間。右 → [3] 昇降分岐塔。

### [3] CarouselJunctionScene 「昇降分岐塔」 (分岐)
- **コンセプト**: 木馬の回転軸に沿った縦の塔。ここで園内 (上) と機関部 (下) に分岐する。
- **構造**: 縦長シーン (高さ約 34)。中段の左から入場。上へはすり抜け床の足場登り → 上出口 (地上へ)。下へは縦穴を降りる → 下出口 (機関部へ)。どちらも素の状態で往復可能。
- **敵**: 中段に地上敵1。
- **接続**: 左(中段) ↔ [2]。上 → [4] 園路。下 → [9] 歯車の縦坑。

### 上ルート (地上・園内。高低差少なめ+坂道、浮遊敵と地上敵)

### [4] UpperPromenadeScene 「木馬の園路」
- 地上に出る。平坦基調 + 緩い坂1つ。地上敵2 + 浮遊敵1 で「空中の敵」を初見せ。天井なし (空)。
### [5] UpperGardenScene 「花壇の遊歩道」
- 緩い坂2つと低い段差。すり抜け床の東屋 (高台) に箱を配置。浮遊敵2 + 地上敵1。
### [6] UpperTerraceScene 「テラス通り」
- 全体に緩い上り基調 (坂+低段差)。浮遊敵2 + 地上敵2 の混成戦。
### [7] UpperRooftopScene 「屋根の上の道」
- 屋根伝いの緩い起伏。浮遊敵3。最奥 (最深部) の入口へ。
### [8] UpperBossArenaScene 「空中木馬の間」 (上中ボス)
- 広い平アリーナ + 低い足場2 (浮遊ボスに届くための台)。**浮遊ボス「舞う木馬」**。扉閉鎖 → 撃破で `UpperBoss`。

### 下ルート (地下機関部。高低差を活かした縦の構成)

### [9] LowerGearShaftScene 「歯車の縦坑」
- 下りの縦坑。すり抜け床で降り、戻りは足場登り。地上敵2。天井あり。
### [10] LowerChainVaultScene 「鎖の大空洞」
- 大空洞。上段・下段の二層構造で、段差とすり抜け床で行き来する。敵3。
### [11] LowerPistonHallScene 「ピストンの回廊」
- 交互に並ぶ高台 (2.0〜2.5 の段差ジャンプの連続)。落ちても下から登り直せる。敵2。
### [12] LowerFlywheelPitScene 「弾み車の底」
- 最深部への下りジグザグ。縦の切り返しジャンプ。敵2。
### [13] LowerBossArenaScene 「大歯車の間」 (下中ボス)
- 長方形 + 両端に一段高い足場。**地上ボス「軸受の重馬」**。扉閉鎖 → 撃破で `LowerBoss`。

## 新規システム (コード)

1. **GameProgress** — 進行フラグの静的管理 (`MidBoss1` / `UpperBoss` / `LowerBoss`)。SaveData.progressFlags に保存され、セーブ/ロードで維持。
2. **BossArena** — 入場トリガーでゲート (壁) を閉め、ボス (EnemyController) の死亡でゲート開放+フラグ記録。フラグ済みならボスを出さずゲートも開けたまま。
3. **ShopKeeper + ShopView** — 拠点のショップ。事前配置の MenuPanelView (実行時生成なし) で、糸を消費してアイテムを購入 (所持数は各アイテムの最大数まで)。
4. **PlayerItemInventoryModel 拡張** — `TryAddItem` (1個追加) / `TrySpendThread` (糸消費)。
5. **浮遊移動の部品** (組み合わせ方式) — `FloatingMotionBase` (重力0化+縦速度ヘルパーの共通基底) を継承した `FloatingChaseMotion` (発見中のみ・緩追尾) と `FloatingPatrolMotion` (常時・ふわふわ水平巡回)。FlyingEnemy.prefab は `CompositeEnemyBehaviour` + この2部品構成で、他の浮遊敵や攻撃部品 (IEnemyAction) との組み合わせに流用できる。速度・巡回幅は EnemyConsts (MoveSpeed/ChaseSpeed/PatrolHalfWidth) を参照。
6. **Blacksmith 解禁条件** — 進行フラグ未達成時は強化を渡さず台詞のみ。

## グレーボックス規約 (このステージ群)

- 地形 = 白〜灰の Square スプライト + BoxCollider2D。すり抜け床 = 緑 (PlatformEffector2D)。
- ボスゲート = 赤系の壁 (BossArena が開閉)。設備 (セーブ/ショップ/鍛冶師) は既存プレハブ+色分け。
- 装飾なし。配置は床・壁・すり抜け床・箱 (一撃破壊)・敵・設備・スポーン/遷移/ヒントゾーンのみ。
- 敵は既存 Enemy.prefab (地上) / FlyingEnemy.prefab (浮遊)。ボスはスケール2倍+Heavy 設定の仮ボス。
