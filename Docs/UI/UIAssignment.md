## 2回目の決定 (タイトル/ロード/ポーズ実装後の質問への回答: 全部おすすめ)
1. 紙と背景の質感: 重ね素材は無し → 紙目と周辺の暗さ (ビネット) をこちらで再現し、完成形の明るさに合わせる (ポーズ背景も完成形の暗さへ)。
2. タイトルの光の枠: 本番の背景素材が来るまで今のまま (完成形画像を背景、PRESS ANY BUTTON の点滅なし)。
3. 選択中の見た目: 今のまま (選んだボタンを 1.06 倍、スロットは 1.04 倍)。選択用の絵が来たら差し替え。
4. 無効の見た目: 今のまま (枠を暗く、文字を半透明)。
5. 記録先の見出し「どのデータに記録しますか?」の重ね方と、上書き時の「上書きしますか? (もう一度決定)」+2回決定: 今のまま。
6. 場所の左のピンのアイコン: 素材待ち (それまで空き)。
7. 章の表示: 「第1章 鳴りやまぬ遊園地」(エリア1 のシーン)。
8. スロットは3つ固定、▼は飾り。
9. 戻る矢印はマウス操作なし (Esc/B の目印)。
10. 「はじめから」の文字は中央揃え。
11. 「メインメニューに戻る」に確認画面を入れる。
12. タイトルの「ゲーム終了」は外したまま。
13. プレイ時間はポーズ・メニュー中は止める。
14. 「はじめから」の開始シーンは `A1_T1`。
15. 拠点でセーブした後は、メニューの選択位置を「セーブ」に戻す。
追加修正: 旧 save.json から移したスロットの章が空・場所にシーン名がはみ出す → 移行時に章/場所を補い、場所の文字が枠からはみ出さないようにする。

## 3回目の決定 (アイテム画面実装後の質問12項目: おすすめ)
1. 確認画面は専用素材が来るまで今の仮のまま (最初は「いいえ」)。
2. 収集品のアイコンはステージの拾い物の絵 (Area1Gen/props の heart_pin / thread_spool など) を仮に使う。攻撃・アイテム・ハサミ強化のアイコンは素材待ち (名前の文字のまま)。
3. 収集品の説明文・日誌本文は文章をもらうまで TODO の仮文。
4. **装備品タブでアイテムスロット (↓・←・→) を付け替えられるようにする** (所持アイテムから選ぶ / はずす。旧ポーズの付け替え処理を流用)。
5. 未入手の日誌は空の枠で表示。長い本文はスクロールできるようにする。
6. 選択中の見た目は今のまま (拡大)。
7. **アイテム画面は毎回「装備品」タブから開く**。
8. **テスト用オーバーレイのパッド操作を Select+R3 から R3 長押しに変える** (Select はアイテム画面専用)。
9. **「ハートピン①」等の丸数字を「ハートピン1」表記に変えて書体をそろえる** (補助フォントを外す)。
10. スロットの章表示は今の2行のまま。
11. ゲーム中のスロット画面の背景は今のまま。
12. **能力 (二段ジャンプ・大ジャンプ・落下攻撃・突進) を取った時の入手通知に操作を1行添える**。特殊攻撃 [K] の説明は足さない。
