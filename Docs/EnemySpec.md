# 敵の挙動仕様 (雑魚4種 + グラミネ第1のボス)

2026-10-10 ユーザーと決定。ボスの元資料 = タスク表 https://docs.google.com/spreadsheets/d/1d6dfv9uyjigFStk4ztBUUFEw7dfQUJ-u3G9WEV5srT0 (タブ「タスク」)。
数値はたたき台。基準 = プレイヤー: 歩き 8 / ダッシュ 20 / ジャンプ高さ 3.33 (二段 6.63) / HP 10。
実装は既存の部品方式 (`CompositeEnemyBehaviour` + `IEnemyMotion` / `IEnemyAction`、`EnemyAttackSelectorBase`) に乗せる。パラメータは各部品の SerializeField / `EnemyConsts` アセット。

## 雑魚

2026-10-10 ユーザー決定で HP を引き上げ (防御値は据え置き)。通常攻撃 Slash (HP 5 / 防御 1) で倒れるまで: Chaser 2 発 / Bundled 4 / Charger 3 / Stomper 3 / FlyingDasher 2 / FlyingShooter 2 (プレイモードで実測)。

### 1. 近づいてくるだけの敵 (Chaser)
- 見つけたらまっすぐ追う。見つける前はゆっくり巡回。足場の端では止まる (落ちない)。
- 追跡速さ 4.5 / 巡回 2 / 発見距離 7 / 見失う距離 10。
- 振り向きに 0.2 秒かかる (飛び越えて背後を取れる)。
- HP 10 / 防御値 2 / 接触ダメージ 1。

### 2. 厚着している敵 (Bundled)
- 防御値ゲージが大きいだけ (既存の重装甲型と同じ考え方)。特殊攻撃・アイテムで崩すのが本命。
- ゆっくり巡回、発見したらプレイヤーの方を向いて歩く。速さ 1.2。
- HP 20 / 防御値 14 / 接触ダメージ 2。

### 3. ウマ (Charger) — 突進
- 巡回 → 正面・ほぼ同じ高さ (縦差 1.5 以内)・距離 8 以内でプレイヤーを発見 → 予備動作 0.6 秒 (前かき・点滅) → 突進。
- 突進: 速さ 12、最大 1.2 秒。接触ダメージ 2。足場の端で止まる。
- 壁に当たる → 1.0 秒ふらつく (無防備)。壁に当たらず終わる → 0.4 秒で減速して停止。
- 再使用まで 1.5 秒。被弾で予備動作は中断。
- HP 15 / 防御値 4。

### 4. ウマ2 (Stomper) — ジャンプ踏みつけ
- 距離 7 以内で発見 → しゃがみ 0.5 秒 (このとき着地点に影の予告) → 跳ぶ瞬間のプレイヤー位置へ放物線 (頂点 高さ5、滞空 0.8 秒)。
- 着地: 踏みつけ判定 (幅 1.6) ダメージ 2。着地後 0.8 秒硬直 (反撃のチャンス)。
- 再使用まで 2 秒。それ以外の間は巡回。
- HP 15 / 防御値 4。

### 5. 飛んで突進してくる敵 (FlyingDasher)
- 浮遊 (重力なし・上下にふわふわ)。見つける前はゆっくり巡回。発見距離 8 / 見失う距離 12。
- 発見後はプレイヤーから約 5 離れた位置を保ってゆっくり寄る。
- 予備動作 0.5 秒 (その場で少し後ろへ下がる+点滅) → 予備動作を始めた時のプレイヤー位置へ一直線に突進 (速さ 14、最大 0.6 秒)。斜めにも突っ込む。
- 突進後 0.8 秒は減速して漂う (反撃のチャンス)。壁・床に当たったら 1.0 秒ふらつく。再使用まで 2 秒。
- HP 10 / 防御値 2 / 接触ダメージ 1 (突進中 2)。

### 6. 飛んで弾を撃ってくる敵 (FlyingShooter)
- 浮遊。発見距離 9 / 見失う距離 13。射撃は視線が通っている時だけ。
- 発見後はプレイヤーの斜め上 (横 6、上 3 くらい) に陣取る。プレイヤーが 4 より近づくと離れる。
- 予備動作 0.4 秒 (点滅) → プレイヤーへ向けて弾を 1 発。弾は遅め (速さ 7) で見てから避けられる。ダメージ 1、壁で消える、**プレイヤーの攻撃で消せる**。再使用まで 2.5 秒。
- HP 8 / 防御値 1 / 接触ダメージ 1。

### 見た目について
専用の絵がまだ無い敵は見た目を変えない (今の仮の見た目・既存プレハブの絵のまま)。予備動作の点滅や影・印などの「動きを伝える最小限の表示」だけ入れる。

## ボス「グラミネ第1のボス」

- **HP 500 / 防御値 20** / ブレイク 3 秒 / 接触ダメージ 1 (2026-10-10 ユーザー指示「弱すぎる、最低でも HP500」。防御値は同日 40 → 20)。
  定数 = `Assets/Prefabs/Enemies/EnemyConsts_BossGramine.asset`、プレハブ = `Assets/Prefabs/Enemies/Boss_Gramine.prefab` (作成 `Docs/Area1/SceneScripts/prep_enemy_spec.cs`)。
- プレイヤーが闘技場 (BossArena のトリガー) に一度入るまでは攻撃しない (入口の手前で被弾して隣の部屋へ押し戻されないように)。

### 登場
- **1戦目 = A1_B1 (B1 ボス部屋)** (仮ボスを差し替え)。第1形態のみ。**HP が半分になったら飛び去る** → 勝ち扱い (フラグ `A1_Boss1`・扉開放)。倒れない。
  - ストーリー: 撤退の瞬間、グラミネの流れ弾 (ナイフ 1 本) が隣の S1 のスピーカー① (`A1_Speaker1`) を誤って壊し、グラミネは奥へ隠れる。
    実装 = `GramineBossBehaviour._retreatBreakTarget` (BreakableSpeaker → `ForceBreak`。フラグ・壊れた絵・扉の灯など、プレイヤーが壊した時と同じ連動)。
    弾が届くまで飛び去りを待つ。スピーカー①が壊れ済みなら撃たない。配線はレシピ `build_A1_B1.cs`。
  - 会話 (宴): 闘技場に入った直後に `A1_Gramine_Meet` (一度きり, フラグ `A1_Gramine_Met`、終わるまで攻撃しない)、
    流れ弾が届いた後に `A1_Gramine_Retreat` → 会話の後に飛び去る (`_introDialogueLabel` / `_introDialogueFlag` / `_retreatDialogueLabel`)。
  - 通知: 流れ弾「グラミネの流れ弾がスピーカー①を壊した…… 拠点の奥の大扉に灯がひとつ点いた (1/3)」→ 撤退「グラミネは奥へ去っていった」。
- **2戦目 = A1_AreaBoss** (エリアボス)。第1形態 → HP 半分で第2形態 → 倒す。

### 構え
- 「浮遊」と「地上」を行き来する (タスク表 1〜6: 浮遊アイドル / 空中移動 / 地面歩く / 地面アイドル / 地面から浮遊 / 浮遊から地面)。
- 浮遊 = 遠距離 (ナイフ)、地上 = 近接・踏みつけ。
- ブレイクすると浮遊中でも地面に落ちる (裁断のチャンス)。

### 第1形態の攻撃 (第2形態でも使う)
| 攻撃 | 構え | 内容 | ダメージ |
|---|---|---|---|
| 踏みつけ | 地上→ | 画面上へ大ジャンプ → 影が 1.0 秒プレイヤーを追う → 0.3 秒固定 → 急降下。着地後 1.5 秒硬直 (大きな隙) | 3 |
| ナイフ投げ | 浮遊 | 0.3 秒光って予告 → 狙い方向へ 3 本扇状。速さ 14 | 1 |
| ステッキ横払い | 地上 | 予告 0.4 秒 → 前方 2.5 を払う | 2 |
| 斜め急降下体当たり | 浮遊→地上 | 予告 0.4 秒 → プレイヤー方向へ斜めに突っ込み地上へ降りる (構えの切り替えを兼ねる) | 2 |
| スピン | 地上 | 近距離 (2 以内) に張り付かれた時。予告 0.3 秒 → 0.6 秒回転、当たると押し返す | 1 |

### 第2形態への遷移
- HP 50% で発動。2 秒無敵、体の一部の色が変わる演出。画面内の弾は消す。

### 第2形態で追加
| 攻撃 | 内容 | ダメージ |
|---|---|---|
| 風船 | 床の 6〜8 か所に 0.8 秒予告 → 下から風船が上昇。通れる隙間を必ず残す | 1 |
| 爆弾投げ | 5 個を散らして投げる。落下点に印 → 着弾 1.0 秒後に爆発、半径 1.5 | 2 |
