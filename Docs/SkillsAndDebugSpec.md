# 要件定義: 移動スキル・スキル専用壁・デバッグ機能

作成: 2026-07-30。対象: 移動スキル3種 (地面落下攻撃 / 大ジャンプ / 横突進)、スキル専用破壊壁、
エディタ用デバッグパネル、およびピストンの回廊 (LowerPistonHallScene) の再設計。

## 1. 移動スキル

メリーゴーランドステージ群クリア後に入手する予定の探索能力。ハサミ強化 (ScissorUpgrade) とは
**別系統** (`PlayerSkill` enum) として管理する。**現時点で正式な入手イベントは実装しない**
(入手手段はデバッグパネルのみ。後続コンテンツで入手ギミックを実装する)。

| スキル | enum | 入力 (仮・変更容易にする) | 挙動 |
|---|---|---|---|
| 落下攻撃 | `GroundSlam=0` | **空中で 下+攻撃** (即発動) | 真下へ急降下 (水平速度0、SlamFallSpeed)。着地時に周囲へ衝撃ダメージ (SlamAttack プロファイル)。降下中に触れた スキル壁(落下) を連鎖的に破壊し、すり抜け床も貫通する |
| 大ジャンプ | `SuperJump=1` | **地上で 上+ジャンプを長押し → 溜め完了後に離して発動** | その場で溜め (SkillChargeTime)。溜め完了前に離すと通常ジャンプ。発動で垂直上昇 — **天井 (砕けない障害物) に当たるまで昇り続け**、最高で SuperJumpHeight (24.5 = 通常3.5の7倍)。途中の スキル壁(大ジャンプ) を破壊し、**敵はダメージを与えながら貫通** (上昇中は無敵) |
| 横突進 | `ChargeRush=2` | **地上で 下+ダッシュを長押し → 溜め完了後に離して発動** | その場で溜め。溜め完了前に離すと通常ダッシュ。発動で向いている方向へ **砕けない障害物に当たるまで突き進み続ける** (ChargeRushSpeed)。途中の スキル壁(突進) を破壊し、**敵はダメージを与えながら貫通** (突進中は無敵)。穴の上も高度を保って飛び越える |
| パリィ | `Parry=3` | **地上で方向入力なしのダッシュ** (即発動) | 受付時間 (ParryWindow) 内に受けた攻撃を無効化。成功で無敵 (ParrySuccessInvincible) を得て即行動可能、失敗すると硬直 (ParryRecovery)。調整は `Docs/CombatTuning.md` 参照 |

### 入力競合の整理
- 下+ジャンプ = すり抜け床降り (既存・不変)。下+攻撃は空中のみ落下攻撃 (地上では従来どおり攻撃)。
- 上入力 = インタラクト (既存・不変)。上+ジャンプはスキル所持時のみ溜めに入る。
- 下+ダッシュはスキル所持時のみ溜めに入る (未所持なら通常ダッシュ)。
- **スキル未所持なら全ての入力が従来の挙動のまま** (回帰なし)。

### 溜めの共通仕様
- 溜め中はその場で停止 (重力は適用)。スプライトを対応スキル色に着色し、溜め完了で白フラッシュ。
- 溜め中に被弾したら通常どおり HurtState へ割り込まれ、スキルは発動しない。

### 定数 (PlayerConsts に追加、インスペクタ調整可)
`SlamFallSpeed=32` / `SlamAttack` (HP2/防御3, Box 3.0×1.6, Offset (0,-0.6)) / `SkillChargeTime=0.4` /
`SuperJumpHeight=24.5` (派生: `SuperJumpVelocity=√(2G·h)`) / `ChargeRushSpeed=26` (時間制限なし・障害物まで)

### 敵の貫通と無敵
敵とプレイヤーは元々物理的に衝突しない (接触ダメージは重なり判定)。突進/大ジャンプ中は
`PlayerController.SetSkillInvulnerable` で接触ダメージを無効化し、装備中の近接攻撃と同じダメージを
1体につき1回与えながら貫通する。

### カメラの下限 (CameraLimit)
`CameraFollow` の下限 `_minY` (既定2) はシーンに `CameraLimit` を置くと上書きできる。
下層エリアを持つステージで使う (ピストンの回廊 = -6 を配置済み)。

### 永続化
- `PlayerProgression` に `HashSet<PlayerSkill>` を追加。`SaveData.skills` (int[]) に保存 (upgrades と同型)。
- enum の int 値はセーブ互換のため**追記のみ可** (既存値の変更禁止)。

## 2. スキル専用破壊壁 `SkillBreakable`

- ハサミ強化壁 (`UpgradeWall` = 赤ハサミの通常攻撃で破壊) とは**別の破壊物**。
- **指定スキルの衝撃でのみ破壊** (`TryBreak(PlayerSkill)` をスキルステートが直接呼ぶ)。
  通常攻撃/ハサミ/裁断ではダメージが通らず、ヒント通知のみ返す (2秒クールダウン)。
- `_flagId` (GameProgress) で破壊状態を永続化。フラグ済みなら Awake で自壊。空なら再入場で復活。
- Ground レイヤーに置く (足場・攻撃対象として振る舞う)。
- グレーボックス色分け: **落下=橙 (0.9,0.55,0.2) / 大ジャンプ=空色 (0.4,0.75,0.95) / 突進=紫 (0.65,0.4,0.85)**。

## 3. デバッグパネル (エディタウィンドウ)

`Assets/Scripts/Editor/DebugPanelWindow.cs`。メニュー **NeverNight/Debug Panel**。
プレイモード中のみ操作可 (非プレイ時は案内表示)。ビルドには一切含まれない (Editor フォルダ)。

| 機能 | 内容 |
|---|---|
| ステージワープ | ビルド設定の GameField シーン一覧をボタン化 → `StageLoader.TransitionTo` |
| 能力の付与/剥奪 | ハサミ強化3種 + スキル3種のトグル |
| 無敵 | `DebugCheats.Invincible` (PlayerHealth.TakeDamage が早期 return) |
| 全回復 | HP全回復 + 回復ゲージMAX |
| 糸+100 | PlayerItemInventory.AddThread |
| 全攻撃解放 | PlayerAttackLoadout のカタログを全て Unlock |
| 敵全滅 | シーン内の EnemyController に致死ダメージ |
| 進行フラグ | 現フラグ一覧 / 任意フラグの Set・Unset / 全クリア |

ランタイム側の追加コードは `DebugCheats` (static bool Invincible) の1点のみ。ゲームUIには手を入れない。

## 4. ピストンの回廊 (LowerPistonHallScene) 再設計

**コンセプト: 小さい足場の上で敵を倒しながら、右上の出口へ登っていく。**

- 問題: 旧足場は段差 4.5〜5.8 で素のジャンプ (3.5) では登れず、次のステージ (弾み車の底) へ到達不能だった。
- 新配置: 幅 2.5〜3 の小足場を上面高さ 2.5 → 5.0 → 7.5 → 10.0 → 12.5 → 14.9 (全段差 ≤2.6) で
  x0〜40 にジグザグ配置。最終段は既存の広い棚 (上面14.9) に接続し右上出口へ。
- 敵: 床の地上敵2 + 足場上の地上敵3 + 中間の浮遊敵1。足場が狭いので戦って落とすか避けて跳ぶかの駆け引き。
- **奥の下り穴** (x45〜48.3): BreakableBox を撤去し、`SkillBreakable(落下攻撃)` 1×1 を2段×3列で封鎖
  (上面は床面に揃え通行可)。下層 (y-7.6) は将来コンテンツ用 + ThreadPickup(20) を配置。

## 5. 受け入れ条件

1. スキル未所持ではすべての操作が従来どおり (すり抜け降り/通常ジャンプ/通常ダッシュ/空中攻撃)。
2. 落下攻撃で穴のブロックを連鎖破壊して下層に到達できる。通常攻撃では壊れずヒントが出る。
3. 大ジャンプは溜め完了後の解放で高さ≈7.5、早期解放は通常ジャンプ。対応壁を破壊できる。
4. 横突進は溜め完了後の解放で突進、対応壁を破壊、敵にダメージ、早期解放は通常ダッシュ。
5. skills がセーブ/ロードで維持される。壁の破壊フラグが永続化される。
6. デバッグパネルの全機能がプレイモードで動作する。
7. ピストンの回廊を素の状態で左→右 (次ステージ)、右→左の双方向に踏破できる。
